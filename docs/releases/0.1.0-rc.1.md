# Gopad++ v0.1.0-rc.1

First public GitHub pre-release of Gopad++, a compact native text editor for Linux.
This is a release candidate for evaluation and feedback, **not a stable release**.

## Highlights

- Compact native editor with tabs, syntax highlighting, find/replace, soft wrap and zoom.
- Audited durable saves, private WAL/shadow recovery, serialized single-instance ownership,
  joined autosave shutdown and stale-search protection.
- Consistent G/++ branding, light/dark themes, window/About/launcher icons and build identity.
- Explicit desktop installation, Linux metadata, bundled third-party notices and reproducible
  archives with checksums. Global Open/Save As/Quit shortcuts work with menus closed.

## Download and install (Linux amd64)

Download the tarball and SHA256SUMS from this release into the same directory, then:

```sh
sha256sum --check --ignore-missing SHA256SUMS
tar -xzf gpad-0.1.0-rc.1-linux-amd64.tar.gz
PREFIX="$HOME/.local" ./gpad-0.1.0-rc.1-linux-amd64/install.sh
"$HOME/.local/bin/gpad" --version
```

Ensure `~/.local/bin` is in your desktop session's PATH. Close an old GPAD instance before
opening the new one. Keep normal file backups; installation retains session data and does
not change default file associations. Ubuntu 24.04 needs GTK 3, libepoxy and OpenGL/EGL
runtime libraries (`libgtk-3-0t64 libepoxy0 libgl1 libegl1`). The archive is not a self-contained
AppImage/Flatpak/DEB. Checksums detect byte damage but are not a publisher signature.

## Validation and limits

Build, tests, race detector, vet, dependency/metadata/asset checks and isolated native X11
GUI smoke tests passed. Dark/light GUI tests cover editing/saving, file forwarding, crash
recovery and shutdown. Published artifacts are built from the clean tagged source and
verified against an independent repeat build; see their bundled build-info and checksums.

Linux amd64 is runtime-tested on Ubuntu 24.04. Linux arm64 is cross-build-only experimental;
no native arm64 binary is published in this release. Hosted CI results are associated with
the release commit. Xvfb software rendering does not establish native Wayland focus, hardware
GPU performance, HiDPI, accessibility or IME readiness.

Known limitations include external file truncation while mmap is in use (possible SIGBUS),
inode metadata changes on atomic save (ACL/xattr/ownership/hard links), and synchronous fsync
latency that can exceed a 120 Hz frame budget. Zero allocations/frame is not achieved.

See [release readiness](https://github.com/thanhnam2811/gpad/blob/v0.1.0-rc.1/RELEASE_READINESS.md)
and [audit verification](https://github.com/thanhnam2811/gpad/blob/v0.1.0-rc.1/AUDIT_VERIFICATION.md)
for evidence, recovery caveats and outstanding stable-release gates. Report issues using
synthetic documents and include `gpad --version`; do not attach personal session WALs/drafts.
